# 📚 SmartLib - Library Management System

SmartLib is a web-based Library Management System designed to automate and streamline library operations. The system provides dedicated modules for Students, Faculty Members, and Librarians, enabling efficient book management, borrowing, request handling, and reporting through a secure role-based platform.

---

## 🚀 Features

### 👨‍🎓 Student Module

* Search books by title, author, or ISBN
* Request available books
* View borrowed books and fine details
* Access issue and return history
* Update profile and password

### 👨‍🏫 Faculty Module

* Priority book request handling
* Extended borrowing duration
* Recommend new books for the library
* View personal borrowing reports

### 📚 Librarian Module

* Add, update, and manage books
* Manage student and faculty accounts
* Issue and return books
* Approve or reject book requests
* Monitor library activities
* Generate library reports

## ⚙️ Installation

1. Install XAMPP.
2. Start Apache and MySQL services.
3. Copy the project folder into the `htdocs` directory.
4. Import `smartlib.sql` using phpMyAdmin.
5. Configure database credentials.
6. Open:

```text
http://localhost/smartlib
```
